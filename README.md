# building-ai-sustainability-agent
Building AI Course – Project Idea Sustainability Agent

## Final project for the Building AI course - an agent for sustainability work

## Summary
The agent is intended to support horizon scanning and business intelligence of sustainability-related laws and regulations in Sweden and at EU level, conduct regulatory analysis, research and benchmarking.
Given the rapid development of the sustainability field, it is particularly important to stay continuously up to date with the latest developments.

## How It Is Used
The agent is intended to make sustainability work more efficient for the user. Over time, a knowledge base will be built up.
The agent’s main use cases include:
- Conducting research and horizon scanning
- Benchmarking companies
- Analysing sustainability legislation and sustainability standards
- Supporting materiality assessments
- Acting as a sounding board on additional environmental, social and governance (ESG) matters

## Data Sources
The agent uses, among other things, the following data sources:
- Laws, directives and regulations
- Consultation documents and legislative proposals
- Guidance from public authorities
- Sustainability standards
- Corporate sustainability reports and annual reports
- Internal governance documents and sustainability data

When conducting research involving laws and regulations, primary sources should always be prioritised, such as EUR-Lex, the European Commission, EFRAG, the Swedish Parliament (Riksdag), the Swedish Government, the Swedish Financial Supervisory Authority (Finansinspektionen), and other relevant public authorities.
For questions concerning current legislation, the agent should always verify information against up-to-date external sources and should not rely solely on static uploaded documents.

## Quality Principles
The agent should:
- Prioritise primary sources
- Distinguish between binding requirements, guidance, established practice and its own assessments
- When conducting regulatory analysis, always cite sources and distinguish between applicable law, proposals, guidance, established practice and the agent’s own analysis
- Provide sources for factual claims
- Ensure traceability to the sources used
- Flag uncertain information
- Never fabricate facts
- Indicate when information needs to be verified against current legislation or standards
- Produce materials that can be reviewed and edited

## Limitations and Challenges
The agent does not replace legal advice, auditing or human expert judgement.
Key challenges include changing regulations and legislation, incomplete or uncertain sustainability data, ensuring that the agent understands company-specific context, and the need for human review when making complex assessments.

## Data and AI Techniques
The techniques used by the agent include LLMs, RAG and web search. The agent’s quality should also be continuously improved through evaluations (evals), documented lessons learned, improved instructions and updated knowledge sources.
